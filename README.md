# ORIÓN DESIGN — sitio web

Sitio responsive en español para presentar la marca, explorar el catálogo y enviar solicitudes de pedido o cotización por WhatsApp.

## Vista local

Abre `index.html` desde un servidor web local para probar la tienda y su panel. También puedes abrir `admin.html` para cargar prendas. El catálogo y la bolsa se guardan en el almacenamiento de ese navegador.

## Catálogo real

El catálogo está vacío intencionalmente: no se recibieron fotos de prendas ni precios al detal. Añade fotos, precio, tallas, colores, stock y datos reales desde Administración. Una prenda no aparece en la tienda hasta que tenga una fotografía y un precio. La interfaz no muestra ni solicita precios mayoristas; ese contacto se prepara con los productos y cantidades por WhatsApp.

El archivo `assets/logo-original.png` conserva exactamente el original adjunto. El sitio usa `assets/orion-design-transparent.png`, una variante donde solo se eliminó el fondo negro; el original permanece intacto.

## Alcance del panel de esta versión

El panel inicial usa `localStorage`: los datos pertenecen a un navegador y no se comparten con otros dispositivos. No tiene autenticación, permisos ni base de datos. Permite altas, cambios, bajas, imágenes optimizadas y respaldo JSON. Es útil para revisar el flujo con datos reales en un navegador. Para una operación compartida o pública hay que conectar una base de datos y un acceso de administración protegido.
