Taxonomía del catálogo

Las categorías iniciales se basan en las referencias compartidas por la marca: Bodys, Conjuntos y Camisas. También puedes elegir “Otros”. Las colecciones se escriben al crear cada prenda y aparecen como filtros en la tienda cuando tienen productos disponibles.

Respaldo y traslado

Exporta el catálogo para guardar una copia o importarlo en otro navegador. Las fotos cargadas también se incluyen en el archivo; guarda la copia de forma privada.

Sobre el panel inicial

La información y las fotos viven en el almacenamiento local del navegador. No hay autenticación, base de datos compartida, control de permisos ni sincronización en línea. Este panel sirve para cargar y revisar datos durante el desarrollo. Para operar públicamente, hace falta conectar el catálogo a un sistema protegido y asegurar que solo el equipo autorizado pueda editarlo.
